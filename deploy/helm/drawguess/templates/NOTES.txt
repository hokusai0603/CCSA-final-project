Volumes (PVCs) and the generated PostgreSQL Secret are kept on `helm uninstall`,
so a reinstall finds the same data and password. Delete both by hand to start over:
  kubectl -n {{ .Release.Namespace }} delete pvc -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ .Release.Namespace }} delete secret {{ include "drawguess.postgres.fullname" . }}
